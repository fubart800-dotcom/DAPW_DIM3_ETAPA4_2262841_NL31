Demostración de Funciones Predefinidas en JavaScript

Bienvenido a la aplicación web interactiva desarrollada para la Dimensión 4: Aplicación. En este laboratorio web exploraremos 4 programas clave orientados a la manipulación de texto, cálculos matemáticos, fechas y estructuras de datos.

1. String Methods

Transformación de texto, longitud, reemplazo de caracteres y limpieza de espacios.

2. Math Object

Potencias, raíces cuadradas, redondeo, valor absoluto y generador aleatorio.

3. Date & Time

Cálculo de diferencia de días, hora en tiempo real y formateo de fechas.

4. Array Methods

Ordenamiento (`sort`), filtrado (`filter`), transformación (`map`) y reversión.
